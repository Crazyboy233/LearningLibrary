# 并行训练策略

## DDP（分布式数据并行）

DDP(Distributed Data Parallel): 每张卡一份完整模型，一份参数，一份梯度。

流程：
- 每个 GPU 拿到不同的 mini-batch。
- 各自做前向、反向。
- 反向时对梯度做 **AllReduce**（全卡求和/平均）。
- 参数在所有卡上保持一致。

优点：
- 通信模型简单，几乎没有魔法。
- 计算和通信可以部分重叠。
- 对算子、autograd、优化器都非常友好。
- 工程稳定性极高，调试体验相对人类友好。

只要模型能完整塞进一张卡，DDP 是首选。缺点也很致命：

> 显存 = 模型参数 * N 卡(每张卡一份)

模型大了直接G。

##  PP 流水线并行

**PP（Pipeline Parallelism）是什么**
把**模型的层按顺序拆分**到不同 GPU。
前一层算完传给下一层，像工厂流水线。

**特点**

- 解决**模型太大、单卡放不下整个网络**
- 会有 bubble 空泡效率损失

**属于**：**模型并行（Model Parallelism）**

## TP 张量并行

**TP（Tensor Parallelism）是什么**
把**一层内部的权重张量切分到多张卡**，比如把矩阵按行 / 列切开，多张卡一起算这一层。

**特点**

- 单层超大时用
- 通信密集

**属于**：**模型并行（张量级并行）**
